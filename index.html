Đồng bộ Chỉ huy
GitHub-only
Máy BCHQS vẫn hoàn toàn offline. Máy đồng bộ nhập file JSON mã hóa rồi ghi file data/latest.json vào chính kho GitHub của PWA. Các máy Chỉ huy khác tự tải bản mới khi mở app.
Nếu app đang mở từ địa chỉ github.io, các ô GitHub phía trên sẽ được tự nhận diện. Repository cần để Public để các máy Chỉ huy đọc bản mã hóa mà không cần token.
Token GitHub chỉ lưu trong Máy đồng bộ và chỉ dùng để cập nhật data/latest.json. Mật khẩu giải mã không được tải lên GitHub.
